# exercicio_supermercado_estatisca

Exercicio desenvolvido no curso Cientista de Dados da EBAC visando desenvolver e aplicar conceitos estatísticos e visualizações de dados através de gráficos apresentados no Módulo 13.

Utilizei como ferramentas as bibliotecas pandas,numpy, plotly, matplotlye seaborn.

O cenário apresentado, de um supermercado chileno, disponibiliza os dados dividos em produto, marca, preço normal, preço desconto (o preço do produto com desconto aplicado), preço anterior, desconto( aplicado ao produto) e a categoria a qual cada um pertence.

No desenvolvimento desde modelo foi possivel identificar a media e a mediana de cada categoria, e observar através da aplicação do desvio padrão que a média não seria a melhor métrica para observação dos preços devido a outliers que acentuam este valor. 

Utilizei um grafico boxplot afim de ilustrar a categoria com maior desvio padrão (Lácteos) e identificar seus outliers. 
Através do gráfico de barras representei  a media de descontos por categoria, finalizando com um gráfico intervativo agrupando os dados por categoria, marca e apresentando suas médias de desconto.
